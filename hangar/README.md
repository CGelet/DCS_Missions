# Mission Hangar

4 campaigns and 30 ready-to-fly DCS missions on the Caucasus, set in 2038.

- **Single mission:** download its `.miz` into `Saved Games/DCS/Missions/` and open it from the Mission menu.
- **Campaign:** copy its folder from `campaigns/` into `Saved Games/DCS/Missions/Campaigns/` and pick it from the Campaign menu.
- **Briefings and slide decks** are HTML, which GitHub only shows as source code. Download the repo (Code → Download ZIP) and double-click `Mission Hangar.html` in its top folder to browse them.

Pilots: briefings, decks and kneeboards only contain what your squadron knows at brief time. Don't open `director.html` before you fly.

These files are generated from `missions/` and `campaigns/`. Don't edit them by hand; see the main README to change a mission.
